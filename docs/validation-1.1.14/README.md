# KAMUCL 1.1.14 — Mac ARM64 恢复构建

本批恢复用户要求的 Mac ARM64，与 Windows x64 共用界面、素材、动效及收藏安装逻辑。Intel Mac、Linux、鸿蒙及资源占用优化仍不在本批范围。已发布 1.1.13 和原证据不覆盖、不改写。

## 产品修复

Mac 陶瓦 v0.4.2 原路径在启动 daemon 后立即调用 `--hmcl`，该客户端可能抢锁并尝试系统 `launchctl`。本批按固定官方协议采用独立 HOME、两字节大端端口与真实 HTTP `/state` 就绪观测，禁止操作共享系统服务。旧持久 16 字节 machine-id 原样使用，不复制旧锁。会话关闭且进程组消失后整体归档会话原文件；退出、归档或路径检查失败时保留文件。Windows 启动协议保持原实现。

协议来源为官方 Terracotta v0.4.2，提交 `70d542156377b316659b4ec2ac62341a43ddc4b2` 的 `src/main.rs`、`src/lock_unix.rs` 与 `src/controller/rooms/scaffolding/mod.rs`，不是新增私有服务解析器。

## 严格保留的历史失败

原生运行 37414805877，源提交 `2946fd7699d8fa3e7e995a55aa3933c23f8940c3`，1.1.13：8 项成功、4 项失败、资源对照按撤回范围跳过。成功包括构建、APP/DMG 界面、默认下载位置、启动、更新及普通 26.2 世界。失败包括陶瓦启动 SIGTRAP、主题初始化实际值不符、APP/DMG 收藏安装后的 1.20.1 世界等待超时。

收藏安装文件和哈希已实际读回；不能据此推断游戏世界通过。两次 jcmd 观测同一拥有进程停在 `glfwCreateWindow → Window.throwGlError → tinyfd_messageBox`，具体弹窗错误文字未取得。普通 26.2 先报 OpenGL `0x10009`，随后用 Vulkan / MoltenVK / Apple Paravirtual 进入世界，因此不证明该虚拟图形设备支持 1.20.1 OpenGL 路径。保留 240 秒原门槛、原录屏和帧时间，不通过改游戏、驱动、画质、运行时或降低断言变成通过。

四次 native sample 在符号处理阶段超时且无完整原生栈。本批修正 QA 将被信号终止的 null 退出码误写成 0，保持超时 incomplete。主题 QA 则观测实际用户目录、持久设置、初始化 store、新 document 和 DOM 后严格断言，避免仅凭固定延时评判。

1.1.14 第一轮原生运行 37417504767（产品源 `c2e4d178ba2bb8f5195e58453eff88b52ad568f2`）已实际验证陶瓦两次独立启动、正常退出、进程组清理、身份保留及原日志归档。主题就绪观测实际通过；完整界面/重启任务随后因 QA 尝试序列化 Node Timeout 对象报错，原任务仍保留失败。用独立 Node inspector 复现相同错误后，仅把诊断表达式的结果改为布尔值，原 500 毫秒退出行为及退出码断言保持。Windows 同轮发现旧回归仍在游戏目录分类寻找已于 1.1.12 移至启动器下载分类的默认位置，已按现有入口补充真实坐标及双分类显隐断言，不移动产品控件。二者均属于 QA 改动，需新的原生结果确认，不把原失败回填通过。

## 放行规则

两平台产品重建和相关回归后，独立评审使用最终成品截图、原始动效与落盘证据分别评分，合理性、功能性、外观均须至少 8.5，无关键缺陷。Mac 必须独立记录 APP、DMG、原生安装、游戏、更新与工具结果。虚拟测试机、已有 Windows 或旧提交通过不替代缺少的原生证据。未通过项继续待验证，不能标记完整移植通过。

Mac ad-hoc 校验只证明包内代码签名完整；未进行 Developer ID 签名或 Apple 公证。人工音效听感尚未覆盖，单独列明。
